# My (mostly shell) scripts ᕕ( ᐛ )ᕗ

Expect many unnecessary comments, as I'm still learning my way around shell
scripting (or scripting in general).

## Scripts

- `backup`          backup your home
- `brownnoise`      play some brown noise with SoX
- `dlsong`          download a song from YT
- `gnome-set-caps`  set the behaviour for the Caps Lock key in Gnome
- `mvi`             interactive move for single files
- `randid`          generate random IDs
- `ratio`           print the ratio between two integer numebers
- `roll`            roll a dice
- `snapshot-notes`  snapshot my $HOME/notes/ folder
- `start-emacs-`
- `test-iems`       test levels for my broken earphones
- `timein`          check the time in other regions
- `ytthumb`         download the thumbnail of a YT video

### Utility scripts

- `pasteimgid.sh`           paste an img from clipboard to `.`
- `permut.bc`               calculate permutations
- `print-usb-partitions.sh`
- `tofilename.pl`           format input into file-name-friendly format
